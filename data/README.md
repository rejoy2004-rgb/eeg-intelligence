# data/

This folder is intentionally empty in version control. **Raw EEG data are not redistributed** (the competition site states only an attribution
requirement and no redistribution terms were found).

Download BCI Competition IV dataset 2a yourself (instructions, checksums and terms: `docs/DATASET.md`) so that you have

```
data/raw/bci_iv_2a/A01T.gdf ... A09E.gdf       (18 files, ~600 MB unzipped)
data/raw/labels_2a/A01T.mat ... A09E.mat       (18 small label files)
```

`data/raw/` and `data/cache/` are git-ignored. Please cite: Brunner, Leeb, Müller-Putz, Schlögl, Pfurtscheller, *BCI Competition 2008 – Graz data set A*.
